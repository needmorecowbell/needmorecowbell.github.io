*This is part 1 of my 2018 Coding Livestream series, where I tackled various programming challenges live.*

## Web Scraping for Location Data

In this livestream, I work through the process of scraping Arby's location data. This involves reverse-engineering their store locator API and building a scraper to collect location information for every Arby's restaurant in America.

Topics covered:
- Inspecting network requests to find hidden APIs
- Working with pagination in web scraping
- Handling rate limiting and being a responsible scraper
